Why the DPI matters for PAN

The DPI is not only a number in the file name. It is stored inside the JPG header, and the portal reads it to work out the physical print size. The tool writes the DPI value into the file header when it exports, so the image prints at the right size on the card.

Photo rules for a PAN card

  • Plain white background, no shadows, no other people in the frame.
  • Face centred, looking straight at the camera, with the full face visible.
  • Normal expression, mouth closed, no sunglasses.
  • Recent photo. Some applications ask for one taken in the last few months.
  • Signature in black ink on white paper, signed the same way as on the form.

Common PAN upload problems

  • "Image dimension is not as per specification" — the pixel size was wrong. Use the preset for your portal instead of guessing.
  • "File size should be less than X KB" — set the maximum KB and let the tool compress it.
  • Signature rejected as unclear — turn on signature cleanup and crop tightly around the signature.
  • Photo rejected for background — retake the photo against a plain white wall.

Questions about the PAN photo resizer

What size is the NSDL PAN photo?

Commonly 3.5 x 2.5 cm at 200 DPI, which is 276 x 197 pixels, with the file under 50 KB.

What size is the UTIITSL PAN photo and signature?

The UTI photo is commonly 213 x 213 pixels and the signature 400 x 200 pixels at 600 DPI in black and white, with strict file size limits.

Does the portal really check DPI?

Some do, because the physical print size is calculated from the DPI stored in the file. The tool writes the chosen DPI into the JPG header when it saves.

Can I apply for a PAN for someone else?

Yes, but the photo and signature must be of the person the card is for. Many people use this tool at CSC or Jan Seva Kendra counters for applicants who cannot upload themselves.
