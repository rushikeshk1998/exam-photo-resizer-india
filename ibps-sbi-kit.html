How to use the kit

  1. Keep the application form open on one screen and this page on the other.
  2. Take all four photos on your phone first: face, signature, thumb, declaration.
  3. Choose each file in its box above. The size and KB range for that document are filled in for you.
  4. Press "process all selected" and check the size shown next to each one.
  5. Download the ZIP, unzip it, and upload the four files to the portal.

Tips that save a rejected form

  • The declaration must contain the exact wording from your application. Many banks reject it when a line is missing or copied incorrectly.
  • Photograph the paper flat, in daylight, with the paper filling the frame. Shadows are the number one reason declarations get rejected.
  • Signatures look grey after compression. The kit cleans up the ink before shrinking it, which is why the signature file stays readable at 140 × 60 pixels.
  • Do not use a cropped screenshot of a signature. Photograph the actual paper.
  • Check every file size in the portal preview before you submit the form.

Questions about the banking application kit

Does the ZIP work on a phone?

Yes. The ZIP is built inside your browser, so it works the same way on Android, iOS, Windows and Mac. On a phone you may need to unzip it with the Files app before uploading.

Can I use a single file for the photo and the signature?

No. The portal checks each upload separately, and the four documents have four different sizes. Prepare each one.

My declaration file is under 50 KB. Is that a problem?

It can be. If the notice states a minimum of 50 KB, turn on "reach minimum KB" and the file is padded with very light noise until it reaches the limit.

Can a cyber cafe operator use this for customers?

Yes. Everything runs in the browser with no signup, so it works on a shared computer. Use the reset button between customers.
