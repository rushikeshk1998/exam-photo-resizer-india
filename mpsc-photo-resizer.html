How to get it right in one attempt

  1. Photograph yourself against a plain white wall in daylight. Avoid the light source being behind you.
  2. Keep the crop tight around your head and shoulders, with white space above the head.
  3. Resize to 276 × 354 pixels and set the file size to the KB range in the notice.
  4. Sign on white paper in black ink for the signature and resize it to 276 × 118 pixels.
  5. Preview both files in the MPSC portal before submitting the form.

Errors that happen most often in Maharashtra forms

  • Photo not in the given dimension — the notice says centimetres, the portal checks pixels. Use 276 × 354 at 200 DPI.
  • File size not in range — set the minimum and maximum KB in the tool.
  • Signature not visible — turn on cleanup and crop tightly.
  • Background not white — retake the photo, or use document mode to whiten the background.

Questions about the MPSC photo resizer

What size is the MPSC photo?

Commonly 3.5 x 4.5 cm, which is 276 x 354 pixels at 200 DPI, with a file size of about 20 to 50 KB.

What size is the MPSC signature?

Commonly 3.5 x 1.5 cm, which is 276 x 118 pixels at 200 DPI, with a file size of about 10 to 20 KB.

Do Maharashtra Police Bharti forms use the same size?

Most recruitment advertisements use a similar photo size, but the pixel and file size values can differ. Read the size line in the advertisement and enter those numbers directly if they differ from the preset.
