KB converter: how to hit an exact file size

Most portals do not accept a file that is too heavy or too light. They say something like "the file size should be between 20 KB and 50 KB" and the upload box checks it.

JPG file size depends on three things: the number of pixels, the JPEG quality, and how much detail the picture has. So a KB converter cannot work on a file that is already compressed. The way to change it is:

  1. Resize to the exact pixel size the portal wants. This is the biggest lever, because every extra pixel adds bytes.
  2. Save as JPG, not PNG. A PNG of the same photo is often 5 to 10 times heavier.
  3. Lower the quality in small steps until the file lands inside the range. The tool does this automatically.
  4. If the file is still under the minimum, which happens with tiny images such as a 140 × 60 pixel signature, turn on the light noise option to add the missing bytes.

Because the pixel count stays exactly what the portal asked for, the file always passes the size check.

DPI converter: why the number in the notification matters

DPI is dots per inch. It tells the portal how large the photo will print, and many portals read it from the JPG header. A 3.5 × 4.5 cm photo at 200 DPI is 276 × 354 pixels, but the same photo at 300 DPI is 413 × 531 pixels and takes up more space in the file.

Passport size photo

A passport size photo is usually 3.5 × 4.5 cm or 4.5 × 3.5 cm, shot on a white background with the face filling the frame. For visa and passport forms the file size limit is often generous, so you can keep good quality. Use the passport size preset above, or set the pixels yourself from the table.

Which size should I pick?

  • Use the pixel size when the portal gives one, for example "200 × 230 pixels" for IBPS.
  • Use the centimetre size when the notice gives one, for example "3.5 × 4.5 cm" for SSC, and pick 200 DPI unless it says otherwise.
  • If both are given, the pixel size wins, because that is what the upload box checks.
  • When a notice is unclear, try the preset and always preview the file in the portal before submitting.

Questions about the photo size converter

How do I convert centimetres to pixels?

Multiply the centimetres by the DPI and divide by 2.54. At 200 DPI, 3.5 cm is 276 pixels and 4.5 cm is 354 pixels.

How do I reduce a photo to exactly 50 KB?

Resize to the required pixel size, save as JPG, then let the tool step the quality down until the file is 50 KB or less. The pixel size is never changed, so the portal check still passes.

What is the difference between DPI and pixels?

Pixels are the width and height of the image. DPI says how many dots fit in an inch, which decides the physical print size. A portal that asks for centimetres needs the DPI value so it can work out the print size from the pixels.

Can I convert a photo to 20 KB for an exam form?

Yes, as long as the pixel size stays exactly as required. If the file will not go below the maximum even at low quality, use a plainer background or fewer pixels, because some portals check both.

Does the converter work on a phone?

Yes. Everything runs in your browser, so it works on any phone or computer without installing anything, and your photo is not uploaded anywhere.
